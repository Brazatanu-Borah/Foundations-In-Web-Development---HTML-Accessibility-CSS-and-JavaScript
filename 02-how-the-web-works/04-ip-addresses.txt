Local IP Address
----------------
  192.168.0.54 [ipv4];          [we also have ipv6]
  - 4 section numbers separated by '.'
  - each section can go from 0 till 999

  >> Every device in our house will have a 'local' ip address, but a main 'global' ip address (modem/router);    
      >> we simple change the last 2 digits (of the global ip address) to get get individual ip addresses for every one of these 'nodes' [devices connected our home network]
        phone       : 192.168.0.55
        computer    : 192.168.0.56
        doorbell    : 192.168.0.57

        (all individual devices of my home network talks to one another as
         people in the same house talks to one another)
         - they can 'see each other' in that house

        global ip address 
          - individual homes in that neighborhood
          - every home will have a permanent/dynamic address seen by everyone in that neighborhood
          - the home(router) may/maynot allow to communicate to devices inside that house

Global IP Address
-----------------
  >> Every device connected to the INTERNET will have unique ip address
  >> My home network address will talk to other devices on the internet using the global ip address

  - also every public device connected to internet has a global ip address

  Website also has an ip address (every domain name will have a gloabl ip address)


    Dynamic IP Address
      >> for home/personal networks [routers/modems]
      >> changes overtime
      >> nobody from the 'internet' requests into my home network and my pc/laptop/tv and files
      >> my pc goes thru my global ip address and out to the internet
      >> my personal global ip address keeps changing, not a big deal (because nobody is looking for my pc files, my address is not important)


    Static IP Address 
      >> For every publicly available website/device
      >> unique identifier on the massive web/internet
      >> Address of the POST OFFICE (fixed address)
      >> everybody will call-in to this webpage; eg google.com
      >> must be always fixed, because many people will be trying to access this website from all diff locations
      >> it cannot change

      - there are workarounds for this fixed address to make dynamic


PING
  - we are asking if 'there is someone' at this particular ip address
  - if there is a website/device at that ip address, it will ping back (yes i'am here)
  - we can also get other info back with advanced pinging techniques
  - not every website allows pinging❌

    >> we get the ip address of the nearest google server/cdn

      $ ping google.com
