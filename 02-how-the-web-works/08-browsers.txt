  Abides by the W3C Standards
  ---------------------------
    >> which browser supports the html tags, css properties, js apis features and which doesn't.
    >> different browser implements standards in different way
      HTML HTML5, CSS, CSS3 etc
      - browser engine must learn all about the standards
      - some may miss one or two features; one browser will support this standard, and another will support these; different browsers implement these stnadrds differently
        WHAT THEY RENDER AND WHAT THEY DON'T, AT WHAT SPEED
      - smae website may miss key pieces in some browsers and fuklly imple,ent them in another
      - 100% standards is never implemented by any browsers

      - 👆 modern browsers are quite standards compliant and very little differences

    speed at which the web page loads (how fast the browser implements the standards)
    render times are different for different browsers (render == reading the code and finally creating them viewable webpage fully); because of the engine underneath
    - hence same website will feel fast or slow depending on the browser that is rendering the webpage, ewven in the same internet speed

  All these different variables combined will finally determine how our website will be experienced by our site visitors
