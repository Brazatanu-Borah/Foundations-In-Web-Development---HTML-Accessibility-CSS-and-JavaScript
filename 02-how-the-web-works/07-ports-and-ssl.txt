  SSL - encrypted info [provides 'end to end security']
    - Keys are available at only the source-location and destination-location
    - data can be locked/unlocked in both locations, but not during the journey
    - my computer and the server will have the info open, but will remain encrypted during the journey
    - problems in both locations - my data is not safe (data is unlocked at both locations, my computer and the server)

        👆Web Server does a lot of things, other than serving up our website files
        --------------------------------------------------------------------------
          Storing website files: It keeps all data, like HTML files, images, style sheets, and videos, in its storage.
          Handling requests: It accepts incoming HTTP or HTTPS requests sent by user web browsers.
          Processing requests: It reads the request to find out which specific web page or file the user wants.
          Delivering content: It sends the requested files back to the browser as an HTTP response so the page can load.
          Virtual hosting: It hosts multiple unique websites on a single physical or cloud server.
          Ensuring security: It uses firewalls and SSL/TLS encryption to protect data and block unauthorized access.
          Managing traffic: It uses caching and load balancing to share heavy traffic and speed up page loading
