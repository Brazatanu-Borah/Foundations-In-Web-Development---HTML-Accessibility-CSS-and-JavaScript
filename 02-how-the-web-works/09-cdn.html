CDN Content Delivery Network Copies of files are stored on various locations (cdn servers) and kept updated regularly Clients will get the file from the closest cdn location to them Only keep the most important files on local hosting company and access all the rest from the cdn locations Every cdn file will have a unique url For eg : jquery cdn urls from different CDN service providers Once retrieved the cdn file will be cached on to the client Cached version will be used until we need the updated version Then we need to remove the cached version, to store the newer version
