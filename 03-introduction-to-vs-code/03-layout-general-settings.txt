Very fast (by default)
Extensible
Lots of plugins (easy to install and uninstall)


|Explorer
  - file/folder tree to see all our project files and folders
  - always open the 'project folder' instead of individual files, evenif ti has only one file
  - creates a 'WORKSPACE' at the root of the folder
  - we can add and remove files in the actual hard drive in real time just from the open folder from within VSCode itself
  - we can have tabs to open multiple files open in the same time
  - we have icons to quickly create files amd folders, refresh the file tree and also search for files and folders inside that project folder
             📃 📁 🔃 ☰


|Search
  - search for any string in files and folders in that WORKSPACE
  ctrl + shift + f
  - search and replace that things inside all files in that folder
     replace replace all


|Source Control
  - not used much
  - best use the inbuilt terminal with cli commands


|Run and Debug
  - we will do more debugging in browser (for html and css, better options)
  - this option is more for JavaScript debugging (along with console tab)
  - launch and run our app for debugging (launch.json)
  - f5


|Extensions
  - lots to customize our personal code editor

        >> C# dev will use extensions customized for C# development
        >> Java dev will use extensions customized for Java development

        Beginner devs will need less extensions

  - tweak existing VS Code settings
  - add new functionality to VS Code

  - some come from official MicroSoft Corp. 'official' others from their respective plugin authors
      >> we have to be careful when selecting extensions

  - more extensions will slow down VSCode

  - TRY to do the task without the help from extensions first, only then install extensions 
    >> this helps us to debug extensions if they cause problems, or tweak the settings in json object
    .. Get The Flow w/o Extensions first!!

    Then our natural coding will speed up with extensions
    
  - avoid 'NIGHTLY' versions of an extension as a beginner
