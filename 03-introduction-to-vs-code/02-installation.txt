Visual Studio Code
===================
  - not Visual Studio

https://code.visualstudio.com/


Open Source Text Editor [for HTML, CSS & JS Coding] most popular
  Many more languages are also supported in this editor
    - Java
    - Docker
    - Node.js

  Text Editor (Fundamentally)
    - designed to edit text
    - we can add plugins to help us write text
    - also supports many languages and technologies

  'Code' is the nickname for this editor
    Set it up to open context menu over files and directory
    Add to path
      'Code .' will open VS Code at that folder

  👆VS Code is built with Electron.js
    - Electron allows to create a Web App that can run as a Desktop App
    - Also is responsive to screen size
    - Hence all web/browser control / shortcuts will work mostly the zoom
      >> [ctrl +] will zoom in
      >> [ctrl -] will zoom out
