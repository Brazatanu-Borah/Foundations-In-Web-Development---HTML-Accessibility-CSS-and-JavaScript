ORGANIZATIONS (Governing bodies for HTML, created and maintained standards)
=============
  IETF took over from CERN
  W3C provided recommendations (1997)
  WHATWG - currently governs all things related to HTML and DOM
    Living Standard of HTML and DOM Standards


  
  1990 - HTML 1 [IETF]
    - laying out text
    - mainly technical documentation

  1995 - HTML 2 [IETF]
    - <img> element
    - styling tags and properties
    - tables for content layout
    - web pages become more aesthetic

  1997 - HTML4 (first W3C recommendation) [start of modern HTML]
    3 types of standards (strict, transitional and frameset)
    - for different types of browser that supported different levels of standards
    - messy times

    Transition phase
    - 2 different standards
    - HTML and XHTML

  2014 - "HTML5" (taken over by WHATWG, W3C only for recommendation)
    Modern Web Standard (mix of technologies)
    - Rich Interactive HTML
    - Mix of HTML and browser API's

  2019 - WHATWG became the main overseer of HTML and DOM standards
    - no version numbering from hereon
    - 'Living Standard'
    - what tag will do what, what tags to be deprecated and what tags will have how much interactivity
    - when the new standrds will be released

    👆 Browsers then try to support all the new standrds that is pushed by the WHATWG
      - always will be slightly behind the actual released standards
      - browser makers always keep an eye out for new standards that are released.


      Modern HTML
      ------------
      Actual content
      'Structure' of the document (not the styling)
      Semantics of the data
              Some default style properties
              Some basic interactivity

        - tags not for actual structure and deprecated by WHATWG should not be used
