## 🚫 What NOT to Expect Here

To keep myself focused, I am intentionally skipping certain topics for now. This repository **does not** cover:

1. **Heavy Frameworks (like React, Vue, or Tailwind)**
   * *Why:* Frameworks change all the time. I want to learn the core coding languages first, because they never change.
2. **WordPress or Content Management Systems (CMS)**
   * *Why:* WordPress is just a tool for quick setup. Real web development means learning how things work under the hood.
3. **Deep Git & GitHub Skills (Source Control)**
   * *Why:* I want to focus on writing HTML, CSS, and JS without getting confused by extra tools. I will study Git later ionce I'm comfortable with the fundamentals.
4. **Server Languages (like C#, PHP, or Java)**
   * *Why:* This course is strictly about code that runs inside your internet browser (frontend), not on a hidden backend server.
